# Adams Afeez — Portfolio

Personal portfolio site — smart contract security research, projects, and audits.

Live: [thegreatfeez.netlify.app](https://thegreatfeez.netlify.app/)

## Stack

React 19, TypeScript, Vite, Tailwind CSS, React Router.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Updating content

All site copy, projects, and audits live in [src/data.ts](src/data.ts) — edit that file and redeploy to update the site.
